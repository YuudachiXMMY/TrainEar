# 内置采样电贝斯

来源：Karoryfer Samples「Black And Blue Basses」(dark black bass, regular pluck, mf 力度层, round robin 1/2)
仓库：https://github.com/sfzinstruments/karoryfer.black-and-blue-basses
授权：CC0 1.0（公有领域，可自由使用与分发）

处理：原始 wav 统一增益归一（峰值 0.85）、裁剪 2.8s、80ms 淡出、mono 96kbps mp3。
命名：<实际发声MIDI>_<roundRobin>.mp3。注意原库按记谱八度标记（标记比实际发声高八度），此处文件名已换算为实际发声音高。
覆盖：MIDI 25 到 54（C#1 到 F#3），缺 48（原库 mf 层空档，播放时由 47 就近变调补）。
